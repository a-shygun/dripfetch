# Security Policy

## Supported Versions

Security updates are provided for the latest release of Dripfetch.

| Version | Supported |
| ------- | --------- |
| Latest | Yes |
| Older releases | No |

## Reporting a Vulnerability

If you discover a security vulnerability in Dripfetch, please report it privately.

Please do not open a public GitHub issue for security vulnerabilities.

You can report vulnerabilities by emailing:

**security@shygun.com**

Please include:

- A description of the vulnerability
- Steps to reproduce it
- The potential impact
- Any relevant logs, screenshots, or proof of concept

I will review the report and respond as soon as possible.
